# VeriDraw

> **Verifiable, on-chain event raffles powered by Solana.**

VeriDraw is a Solana-based raffle platform that enables organizers to create events, register participants, select winners using **verifiable Switchboard randomness**, and issue **Compressed NFTs (cNFTs)** as winner certificates.

## Features

*  Create and manage events on-chain
*  Register participants using PDAs
*  Verifiable randomness with Switchboard On-Demand
*  Multiple, duplicate-free winner selection
*  Metaplex Bubblegum cNFT winner certificates

## Tech Stack

* **Solana / Anchor / Rust**
* **Switchboard On-Demand**
* **Metaplex Bubblegum + Umi**
* **React + Vite + TypeScript**
* **Solana Wallet Adapter**
